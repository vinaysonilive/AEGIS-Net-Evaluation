# AEGIS-Net-Evaluation
Official implementation of AEGIS-Net: A compact hybrid CNN-BiLSTM framework with attention and selective SMOTE for high-throughput, long-tailed multi-class IoT botnet detection. Features quantitative XAI (LIME/IG/SHAP) and edge deployment benchmarks on CICIoT2023, CICIoMT2024, and CIC IoT-DIAD 2024.
